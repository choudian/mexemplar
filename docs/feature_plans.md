### 当前已知 BUG

| BUG ID | 优先级 | 状态 | 描述 | 预计修复时间 |
|-------|--------|------|------|--------------|
| BUG-001 | 🔴 高 | ⏳ 修复中 | WebSocket 连接偶尔断开 | 2026-01-24 |
| BUG-002 | 🟡 中 | ⏳ 待修复 | DuckDB 并发写入冲突 | 2026-01-25 |
| BUG-003 | 🟢 低 | ⏳ 待修复 | 某些站点截图失败 | 2026-01-28 |

**BUG 修复流程**：

1. **发现 BUG** → 添加到 BUG 修复计划
2. **优先级评估** → 🔴 高 / 🟡 中 / 🟢 低
3. **修复 BUG** → 创建修复分支 `fix/bug-xxx`
4. **测试验证** → 单元测试 + 集成测试
5. **合并代码** → PR 到主分支
6. **更新文档** → 标记为已修复

**当前 BUG 修复重点**：
- 🔴 BUG-001: WebSocket 连接稳定性（高于新功能开发）
- 🟡 BUG-002: 并发安全（高于新功能开发）

6. ✅ **BUG 修复**: 已知 BUG 全部修复
