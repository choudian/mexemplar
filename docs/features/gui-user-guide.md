## 🚀 启动应用

### Windows 用户

双击项目根目录下的 `mexemplar_gui.bat` 文件即可启动图形界面。

### 所有平台

在命令行中运行：

```bash
# 使用 uv 运行
uv run python -m src.main --gui

# 或直接运行 Python 脚本
python mexemplar_gui.py
```

### 启动要求

- ✅ Python 3.11+ 已安装
- ✅ 项目依赖已安装（运行 `uv sync`）
- ✅ 配置文件已初始化（首次运行会自动创建）

## 🏠 主界面

启动后，你会看到主界面，提供四个主要功能：

### 1. 📹 开始录制

录制你的浏览器或桌面操作，让 AI 学习你的工作流程。

**功能**：
- 浏览器操作录制
- 桌面操作录制
- 自动捕获网络请求
- 智能事件过滤

### 2. ▶️ 执行工具

执行已生成的自动化工具。

**功能**：
- 查看所有工具列表
- 一键执行工具
- 查看执行历史
- 参数化执行

### 3. 📊 工具列表

管理所有已生成的工具。

**功能**：
- 查看工具详情
- 编辑工具定义
- 删除工具
- 导入/导出工具

### 4. ⚙️ 设置

配置应用参数。

**功能**：
- AI 模型配置
- 录制选项
- 浏览器设置
- 数据存储配置

### 菜单栏

主界面顶部提供菜单栏：

- **文件**
  - 退出（快捷键：Ctrl+Q）

- **帮助**
  - 关于 Mexemplar

## 📹 录制操作

### 开始录制

1. 点击主界面的 **"📹 开始录制"** 按钮
2. 进入录制配置页面

### 录制配置

#### 录制模式

**浏览器录制**：
- 用于录制网页操作
- 支持自动捕获网络请求
- 需要 Chrome 或 Edge 浏览器

**桌面录制**：
- 用于录制桌面应用程序操作
- 自动捕获窗口元素
- 支持任意桌面软件

#### 起始 URL（可选）

- 对于浏览器录制，可以设置起始 URL
- 录制开始时会自动打开此 URL
- 留空则手动打开浏览器

### 录制过程

1. 点击 **"▶️ 开始录制"** 按钮
2. 根据模式进行操作：
   - **浏览器模式**：在浏览器中进行操作
   - **桌面模式**：操作目标应用程序
3. 完成后点击 **"⏹️ 停止录制"** 按钮
4. 点击 **"← 返回"** 回到主界面

### 录制状态

录制过程中，界面会显示：

- **进度条**：显示录制进度
- **状态文本**：实时显示录制日志和状态信息

## ▶️ 执行工具

### 查看工具列表

点击主界面的 **"▶️ 执行工具"** 按钮查看所有可用工具。

### 执行工具

1. 在工具列表中选择要执行的工具
2. 查看工具描述和参数
3. 点击 **"执行"** 按钮
4. 工具将自动执行你之前录制的操作

### 执行历史

- 每次执行都会记录日志
- 可以查看执行结果和错误信息
- 支持重新执行失败的任务

---

## 📊 工具管理

### 查看工具详情

点击主界面的 **"📊 工具列表"** 按钮：

- 查看所有已生成的工具
- 查看工具的描述和参数
- 查看工具的执行代码

### 编辑工具

- 修改工具名称和描述
- 调整工具参数
- 编辑执行代码（高级功能）

### 删除工具

- 选择不再需要的工具
- 点击删除按钮
- 确认删除操作

### 导入/导出工具

- **导出工具**：将工具保存为文件，便于分享
- **导入工具**：从文件加载工具定义

## ⚙️ 应用设置

点击主界面的 **"⚙️ 设置"** 按钮进入设置页面。

### AI 模型配置

- **API Key**：设置 Anthropic Claude API Key
- **模型选择**：选择使用的 AI 模型
- **超时设置**：设置 API 调用超时时间

### 录制选项

- **默认录制模式**：选择默认的录制模式（浏览器/桌面）
- **浏览器起始 URL**：设置默认的起始 URL
- **自动捕获网络请求**：是否自动捕获网络请求
- **事件过滤级别**：选择事件过滤的严格程度

### 浏览器设置

- **浏览器类型**：选择使用的浏览器（Chrome/Edge）
- **用户数据目录**：设置浏览器用户数据目录
- **无头模式**：是否使用无头浏览器

### 数据存储

- **数据库位置**：查看数据库存储位置
- **数据备份**：设置自动备份选项
- **数据清理**：清理过期数据

## ❓ 常见问题

### Q1: 如何启动图形界面？

**A**: 有三种方式：

1. 双击 `mexemplar_gui.bat`（Windows）
2. 运行 `uv run python -m src.main --gui`
3. 运行 `python mexemplar_gui.py`

### Q2: 录制时浏览器没有反应？

**A**: 请确保：

1. 已安装浏览器扩展（Chrome/Edge）
2. WebSocket 服务器正常运行
3. 浏览器扩展已启用

### Q3: 录制后的工具在哪里？

**A**: 录制完成后，AI 会自动分析并生成工具：

- 工具保存在本地数据库中
- 点击 **"执行工具"** 或 **"工具列表"** 查看
- 可以随时执行、编辑或删除

### Q4: 如何离线使用？

**A**: Mexemplar 支持完全离线使用：

- **执行阶段**：完全离线，无需联网
- **录制阶段**：本地录制，无需联网
- **生成工具**：需要调用 AI API，需要联网

### Q5: 数据存储在哪里？

**A**: 所有数据存储在本地：

```
data/
├── mexemplar.db          # SQLite 业务数据库
│   ├── tools            # 工具定义
│   ├── task_executions  # 执行记录
│   └── conversations    # 对话历史
│
└── recordings/
    └── exemplar.duckdb  # DuckDB 录制数据库
        ├── recording_sessions
        ├── actions
        └── network_requests
```

### Q6: 如何备份数据？

**A**: 有多种备份方式：

1. **手动备份**：复制 `data/` 目录
2. **自动备份**：在设置中启用云端备份
3. **导出工具**：将工具导出为文件

### Q7: 录制失败怎么办？

**A**: 检查以下内容：

1. 浏览器扩展是否已安装并启用
2. WebSocket 服务是否正常运行（端口 8765）
3. 查看状态文本中的错误信息
4. 检查日志文件（`logs/mexemplar.log`）

### Q8: 如何提高录制准确性？

**A**: 最佳实践：

1. **操作慢一点**：给 AI 时间理解每一步
2. **明确操作**：点击明显的元素，避免模糊区域
3. **完整流程**：一次性录制完整的操作流程
4. **测试验证**：录制后立即执行测试

### Q9: 支持哪些浏览器？

**A**: 当前支持：

- ✅ Google Chrome
- ✅ Microsoft Edge
- ⏳ Firefox（计划中）
- ⏳ Safari（计划中）

### Q10: 如何获取 AI API Key？

**A**:

1. 访问 [Anthropic Console](https://console.anthropic.com/)
2. 注册/登录账号
3. 在 API Keys 页面创建新的 API Key
4. 在 Mexemplar 设置中输入 API Key
