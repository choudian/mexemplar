# AI 助手对话界面功能说明

## 📋 功能概述

AI 助手对话界面提供了一个直观的聊天界面，允许用户与 AI 进行自然语言交互，获取帮助、解答疑问等。

## 🎨 界面布局

### 主界面按钮

在主界面的"开始录制"按钮上方，新增了 **"🤖 AI 助手"** 按钮：

- **颜色**：红色主题（#e74c3c）
- **位置**：所有功能按钮的最上方
- **功能**：点击后切换到 AI 对话界面

### 对话界面布局

对话界面采用 **左右分割布局**：

#### 左侧面板（25% 宽度）

1. **对话历史列表**
   - 显示历史对话记录
   - 点击可切换对话
   - 悬停高亮效果

2. **新建对话按钮**
   - 位置：历史列表上方
   - 功能：清空当前对话，创建新对话
   - 颜色：蓝色（#3498db）

#### 右侧面板（75% 宽度）

右侧面板采用 **上下分割布局**：

**上部区域（70% 高度）- 消息展示**

- 对话标题显示
- 可滚动的消息区域
- 消息气泡样式：
  - **用户消息**：蓝色背景（#3498db）
  - **AI 消息**：灰色背景（#ecf0f1）
- 角色标识：
  - 👤 用户
  - 🤖 AI 助手

**下部区域（30% 高度）- 输入区域**

- 提示文字："输入消息，按 Enter 发送"
- 多行文本输入框（最大高度 100px）
- 发送按钮：
  - 位置：右下角
  - 颜色：绿色（#27ae60）
  - 初始状态：禁用
  - 输入文字后：启用
  - 悬停效果：深绿色（#229954）

## 🎯 交互功能

### 1. 新建对话

点击"＋ 新建对话"按钮：
- 清空当前消息区域
- 重置对话标题为"新对话"
- 显示欢迎消息

### 2. 发送消息

**方式一**：点击发送按钮
- 输入框输入文字
- 点击"发送 📨"按钮

**方式二**：Enter 键（待实现）
- 当前仅支持按钮发送
- 未来可添加快捷键支持

### 3. 消息显示

**用户消息**：
- 蓝色气泡背景
- 左对齐显示
- 显示"👤 你"标签

**AI 消息**：
- 灰色气泡背景
- 左对齐显示
- 显示"🤖 AI 助手"标签

### 4. 返回导航

- 点击左上角"← 返回"按钮
- 返回主界面

## 🚀 使用示例

### 启动对话界面

```bash
# 方式一：双击批处理文件
mexemplar_gui.bat

# 方式二：命令行
uv run python mexemplar_gui.py

# 然后点击 "🤖 AI 助手" 按钮
```

### 发送消息

1. 在输入框中输入问题
2. 点击"发送 📨"按钮
3. 等待 AI 响应（当前为模拟响应）

### 新建对话

1. 点击左侧"＋ 新建对话"按钮
2. 消息区域清空
3. 显示欢迎消息
