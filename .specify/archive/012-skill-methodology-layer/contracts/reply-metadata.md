```python
def reply_to_user_handler(
    text: str,
    memory_entries_referenced: list[str] | None = None,
    skills_referenced: list[str] | None = None,
) -> ToolSignal:
    # 既有 memory_entries_referenced 处理...
    
    # 新增 skills_referenced 处理（同构）
    if isinstance(skills_referenced, list) and all(
        isinstance(skill_id, str) for skill_id in skills_referenced
    ):
        skill_ids = [
            skill_id.strip() for skill_id in skills_referenced if skill_id.strip()
        ]
    else:
        skill_ids = []
    
    if skill_ids:
        try:
            with SkillRepository() as repo:
                # 按 supersede 链根归一化（详见 normalize_to_chain_active 下文）
                normalized = repo.normalize_to_chain_active(skill_ids)
                if normalized:
                    repo.batch_increment_referenced_counts(normalized)
        except Exception as e:
            logger.warning("[reply_to_user] skills_referenced +1 失败: %s", e)
    
    return ToolSignal(result_type=ResultType.NEEDS_USER_INPUT, display_text=text)
```

## Supersede 链根归一化算法（FR-041 / SC-016f-h）

`SkillRepository.normalize_to_chain_active(skill_ids: list[str]) → list[str]`:

```python
def normalize_to_chain_active(self, skill_ids):
    """
    把每个 skill_id 沿 supersede 链回溯到 chain_root，
    再查 chain_root 当前 active 版本（status='active' AND chain_root_id == chain_root_id）。
    
    返回值：归一化后的 active skill_id list（已去重）。
    - 已 soft_deleted chain_root → 该 skill_id 被剔除（视为"asset 已不存在"按 FR-041 静默跳过）
    - 同一轮多条引用归一化指向同一 chain_root → 去重为 1 条
    """
    seen_chain_roots = set()
    result = []
    for sid in skill_ids:
        chain_root = self._resolve_chain_root(sid)
        if chain_root is None:
            continue  # skill_id 不存在
        if chain_root in seen_chain_roots:
            continue  # 同一轮重复列出去重
        seen_chain_roots.add(chain_root)
        
        active = self._get_chain_active(chain_root)
        if active is None:
            continue  # chain 已全部 soft_deleted 或无 active 版本（fail-soft）
        result.append(active.skill_id)
    return result
```

`_resolve_chain_root(skill_id)` 走冗余字段 `chain_root_id`（详见 data-model.md），O(1) 查询。
`_get_chain_active(chain_root_id)` 走 `WHERE chain_root_id = ? AND status = 'active'`，索引命中。

## 与既有 `memory_entries_referenced` 的关系

| 维度 | `memory_entries_referenced` (010) | `skills_referenced` (012) |
|------|-----------------------------------|---------------------------|
| 类型 | `list[str]` | `list[str]` |
| 字段缺失策略 | 静默跳过 | 静默跳过 |
| 同一轮重复列出 | 不去重（既有行为） | **去重**（FR-041 / SC-016c / SC-016h） |
| 归一化处理 | 无 | **supersede 链根归一化**（FR-041 / SC-016f-h） |
| 不存在 / 已删除 entry | 静默跳过 | 静默跳过 |
| 写入路径 | `BrainRepository.batch_update_referenced_counts` | `SkillRepository.batch_increment_referenced_counts` |

注：`memory_entries_referenced` 是否需要补上同等的"链根归一化"超出本 feature 范围（010 范围内 memory_entries 没有 supersede 链 vs version 的 asset 视角，故无需归一化）。
