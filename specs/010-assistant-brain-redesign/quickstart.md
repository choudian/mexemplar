## 实现顺序建议（P1）

```
1. v11 migration（migrate_to_v11）— 建全所有表
2. ORM 模型（models_sqlite.py）— 6 张新表
3. BrainRepository — MemoryEntry / Segment CRUD + 原子状态转换
4. 新增 events.py 信号 — brain_zone_changed 等 6 个
5. DistillationService — Segment 状态机 + 单次 LLM 工具调用（P1 schema: hot + persistent）
6. BrainContextBuilder — 热区 top-N + 持久区全量注入 + brain_context_ready 事件
7. 更新 AssistantPromptBuilder — 从 BrainContextBuilder 读取上下文
8. BrainBackgroundWorker — daemon thread，处理 pending segments
9. desktop_api /api/brain/* 路由（P1 范围：zone GET）+ 助理 Segment 边界端点（idle 与显式 boundary）
10. 前端空闲计时器调用 segment-idle；新建/切换会话和窗口关闭调用 segment-boundary 并传递 reason
11. 更新 format_assistant_prompt — 冷启动破冰路径（大脑全空时，破冰答案经沉淀路由为持久区条目）
```

## 沉淀 LLM 工具 Schema 参考（distillation_output）

沉淀工具 schema 按 phase 裁剪，只包含当前 phase 已激活写入的分区。不要在 P1/P2 请求尚未激活的分区再丢弃结果；猜测区条目由 P4 的周期性 prediction generation worker 生成，不属于 Segment 沉淀输出。

```python
def build_distillation_tool_schema(active_zones: list[str]) -> dict:
    properties = {
        "hot_zone": {
            "type": "array",
            "items": {
                "type": "object",
                "required": ["content", "entry_type", "reason"],
                "properties": {
                    "content": {"type": "string"},
                    "entry_type": {"type": "string", "enum": ["event", "insight"]},
                    "scope": {"type": "string"},
                    "reason": {"type": "string"}
                }
            }
        },
        "persistent_zone": {
            "type": "array",
            "items": {
                "type": "object",
                "required": ["content", "reason"],
                "properties": {
                    "content": {"type": "string"},
                    "scope": {"type": "string"},
                    "reason": {"type": "string"}
                }
            }
        },
        "archive_zone": { "type": "array", "items": {"...": "segment-level historical event / summary"} },
        "subconscious_zone": { "type": "array", "items": {"...": "偏好/价值观/风格/反感"} },
        "failure_zone": { "type": "array", "items": {"...": "含 scope 字段"} },
    }

    return {
        "name": "distillation_output",
        "description": "输出对该 Segment 的多分区记忆沉淀结果",
        "input_schema": {
            "type": "object",
            "required": active_zones,
            "properties": {zone: properties[zone] for zone in active_zones},
        },
    }

P1_DISTILLATION_TOOL_SCHEMA = build_distillation_tool_schema([
    "hot_zone",
    "persistent_zone",
])

P2_DISTILLATION_TOOL_SCHEMA = build_distillation_tool_schema([
    "hot_zone",
    "persistent_zone",
    "archive_zone",
])

P4_DISTILLATION_TOOL_SCHEMA = build_distillation_tool_schema([
    "hot_zone",
    "persistent_zone",
    "archive_zone",
    "subconscious_zone",
    "failure_zone",
])
```

归档区 P2 起可以接收 Segment 级历史条目；归档分层工作（archive layering job）再把这些条目递进聚合为日 / 周 / 月等层级。猜测区条目由 prediction generation worker 基于跨 Segment 上下文生成，schema 不含 `prediction_zone`。

        "properties": {

                "type": "array",
                "items": {
                    "type": "object",
                    "required": ["content", "verification_checkpoint", "reason"],
                    "properties": {
                        "content": {"type": "string"},
                        "verification_checkpoint": {"type": "string"},
                        "reason": {"type": "string"}
                    }
                }
            }
        }
    }
}
