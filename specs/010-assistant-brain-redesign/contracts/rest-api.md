## 大脑分区管理

### `GET /api/brain/zones`

返回 6 个分区的汇总信息（条目数、分类）。

**Response**:
```json
{
  "zones": [
    {
      "zone": "hot",
      "label": "热区",
      "entry_count": 12,
      "fading_count": 3
    },
    { "zone": "persistent", "label": "持久区", "entry_count": 8 },
    { "zone": "archive", "label": "归档区", "entry_count": 142 },
    { "zone": "subconscious", "label": "潜意识区", "entry_count": 7 },
    { "zone": "failure", "label": "失败区", "entry_count": 5 },
    { "zone": "prediction", "label": "猜测区", "entry_count": 3 }
  ]
}
```

---

### `GET /api/brain/zones/{zone}/entries`

列出指定分区的条目（分页，不含 `soft-deleted`）。

**Path**: `zone` ∈ `{hot, persistent, archive, subconscious, failure, prediction}`  
**Query params**: `limit=50`, `offset=0`, `status=active,fading,invalidated`（逗号分隔，默认全部非 soft-deleted）

**Response**:
```json
{
  "items": [
    {
      "entry_id": "uuid",
      "zone": "hot",
      "entry_type": "event",
      "content": "...",
      "status": "active",
      "origin": "distillation",
      "reason": "...",
      "scope": null,
      "loaded_count": 5,
      "referenced_count": 3,
      "superseded_by": null,
      "verification_checkpoint": null,
      "verification_status": null,
      "verification_rationale": null,
      "created_at": "2026-05-20T10:00:00Z",
      "updated_at": "2026-05-20T10:00:00Z"
    }
  ],
  "total": 12,
  "limit": 50,
  "offset": 0
}
```

---

### `PUT /api/brain/entries/{entry_id}`

用户在管理界面编辑条目。产生新的替代条目，旧条目 `superseded_by = new_entry_id`, `status = soft-deleted`。同时写入 `feedback_signals` 表。

**Body**:
```json
{
  "content": "更新后的内容",
  "scope": "可选的新适用范围"
}
```

**Response**: 新条目完整对象（同 GET 格式）。

---

### `DELETE /api/brain/entries/{entry_id}`

用户在管理界面软删除条目（`status = soft-deleted`）。同时写入 `feedback_signals` 表。

**Response**: `204 No Content`

---

### `GET /api/brain/entries/{entry_id}/evolution`

获取条目的演化链（通过 `superseded_by` 链遍历，从最旧到最新）。

**Response**:
```json
{
  "chain": [
    { "entry_id": "uuid-old", "content": "...", "status": "soft-deleted", "created_at": "..." },
    { "entry_id": "uuid-new", "content": "...", "status": "active", "created_at": "..." }
  ]
}
```

## Segment 管理

### `GET /api/brain/segments`

列出 Segment（分页）。

**Query params**: `limit=20`, `offset=0`, `status=all|pending|failed`

**Response**:
```json
{
  "items": [
    {
      "segment_id": "uuid",
      "session_id": "uuid",
      "status": "failed",
      "retry_count": 3,
      "boundary_reason": "window_close",
      "sealed_at": "2026-05-20T08:00:00Z",
      "completed_at": null,
      "created_at": "2026-05-20T08:00:00Z"
    }
  ],
  "total": 5
}
```

---

### `POST /api/brain/segments/{segment_id}/retry`

用户手动触发失败 Segment 的重试（状态从 `failed` → `pending`，触发 worker 重新处理）。

**Response**: `200 { "segment_id": "...", "status": "pending" }`

列出所有活跃专员。

```json
  "items": [
    {
      "specialist_id": "uuid",
      "name": "数据分析专员",
      "description": "...",
      "role_definition": "...",
      "tool_whitelist": ["tool_id_1", "tool_id_2"],
      "origin": "auto_recruitment",

    }

```

---

### `POST /api/brain/specialists`

用户在管理界面手动创建专员。

**Body**:
```json
{
  "name": "文案专员",
  "description": "负责起草对外文案",
  "role_definition": "你是一名专注于对外文案...",
  "tool_whitelist": ["tool_id_a"]
}
```

**Response**: 新专员完整对象。

---

### `PUT /api/brain/specialists/{specialist_id}`

更新专员（产生新版本记录）。

**Body** (部分字段均可选):
```json
{
  "name": "新名称",
  "description": "新描述",
  "role_definition": "新角色定义",
  "tool_whitelist": ["tool_id_a", "tool_id_b"]
}
```

**Response**: 更新后的专员对象。

---

### `DELETE /api/brain/specialists/{specialist_id}`

软删除专员（`is_active = 0`）。

**Response**: `204 No Content`

## 技能池管理

### `GET /api/brain/skill-pool`

返回当前 assistant 可用的全部技能（工具列表，作为专员白名单的超集）。

**Response**:
```json
{
  "skills": [
    { "tool_id": "uuid", "name": "分析报表", "description": "..." }
  ]
}
```

---

### `DELETE /api/brain/skill-pool/{tool_id}`

从技能池移除工具。

- 若有专员白名单引用该工具：返回 `409 Conflict`，body 含受影响专员列表。
- 若请求带 `?force=true`：从所有专员白名单中自动裁剪该工具后删除。

**Response（正常）**: `204 No Content`  
**Response（冲突）**:
```json
{
  "error": "skill_in_use",
  "affected_specialists": [
    { "specialist_id": "...", "name": "数据分析专员" }
  ]
}
```

## 助理会话扩展（现有端点扩展）

### `POST /api/assistant/sessions/{session_id}/segment-idle`

前端空闲计时器触发后调用，通知后端封存当前 Segment（触发 `segment_boundary_triggered` blinker 事件）。

**Body**:
```json
{ "session_id": "uuid" }
```

**Response**: `200 { "segment_id": "uuid", "status": "pending" }`

### `POST /api/assistant/segment-boundary`

前端在非空闲的显式边界触发后调用，包括新建/切换会话、窗口关闭和 token limit。后端按请求中的 `reason`
封存当前 Segment，并触发 `segment_boundary_triggered` blinker 事件。

**Body**:
```json
{ "session_id": "uuid", "reason": "new_session" }
```

`reason` 允许值：`window_close`、`new_session`、`token_limit`。

**Response**: `200 { "segment_id": "uuid", "status": "pending" }`

## 错误码约定

| HTTP 状态 | `error` 值 | 说明 |
|-----------|-----------|------|
| 404 | `not_found` | 资源不存在 |
| 409 | `skill_in_use` | 技能被专员引用，无法直接移除 |
| 409 | `invalid_zone` | 无效的分区名称 |
| 422 | `validation_error` | 请求体格式不合法 |
| 500 | `internal_error` | 服务端错误 |
