## 新增 Blinker 事件（src/utils/events.py）

### `brain_zone_changed`

大脑任意分区的条目状态变化（新增 / 软删 / 失效 / 状态迁移）。  
**触发方**: `BrainRepository` 的写操作方法。  
**消费方**: desktop API event stream adapter 和前端 brain store。当前实现不维护后端 prompt
cache；事件用于通知前端刷新管理界面，下一次 assistant 运行会在工作线程内同步重建上下文。

**Payload**:
```python
{
    "zone": str,          # 'hot' | 'persistent' | 'subconscious' | ...
    "entry_id": str,      # 变化的条目 ID
    "operation": str,     # 'create' | 'status_update' | 'soft_delete' | ...
}
```

---

### `brain_specialist_changed`

专员列表发生变化（新增 / 更新 / 软删）。  
**触发方**: `SpecialistRepository` 的写操作方法。  
**消费方**: 当前不维护后端 prompt cache；下一次 assistant 运行会同步读取最新专员列表。

**Payload**:
```python
{
    "specialist_id": str,
    "operation": str,     # 'create' | 'update' | 'delete'
}
```

---

### `segment_boundary_triggered`

Segment 边界事件：当前 open segment 被封存，进入 `pending` 状态。  
**触发方**: `SegmentService`（响应 window_close、idle trigger、new session、token limit）。  
**消费方**: `BrainBackgroundWorker`——被唤醒，开始处理 `pending` segments。

**Payload**:
```python
{
    "session_id": str,
    "segment_id": str,
    "reason": str,        # 'window_close' | 'idle' | 'new_session' | 'token_limit'
}
```

---

### `segment_idle_trigger`

前端空闲计时器触发，desktop API adapter 收到后调用 `SegmentService`，再触发 `segment_boundary_triggered`。  
**触发方**: desktop API 路由（接收前端 `POST /api/assistant/sessions/{id}/segment-idle`）。  
**消费方**: `SegmentService`.

**Payload**:
```python
{
    "session_id": str,
}
```

显式边界（`window_close`、`new_session`、`token_limit`）由 desktop API 路由
`POST /api/assistant/segment-boundary` 直接传入 `SegmentService.seal_segment()`，并使用请求中的
`reason` 继续触发同一个 `segment_boundary_triggered` 事件。

---

### `brain_specialist_recruited`

自动招募完成：新专员已创建。  
**触发方**: `BrainBackgroundWorker`（专员招募扫描完成后）。  
**消费方**: desktop API event stream adapter——转发为前端 SSE 事件。

**Payload**:
```python
{
    "specialist_id": str,
    "name": str,
    "reason": str,
}
```

---

### `brain_context_ready`

助理大脑上下文构建完成。构建发生在 assistant 后台工作线程的 prompt 准备阶段；UI 线程不等待，
assistant 的首轮 LLM 调用在该同步构建完成后继续。  
**触发方**: `BrainContextBuilder`（构建完成后 emit）。  
**消费方**: desktop API event stream adapter 和前端 brain store（可刷新管理界面或展示就绪状态）。

**Payload**:
```python
{
    "session_id": str,
}
```

## 新增前端 SSE 事件类型（`/api/events` stream）

前端 `connectEvents()` 解析后，通过各 store 的 `applyEvent()` 处理。

### `brain_zone_changed`

通知前端大脑管理模块刷新分区条目列表。

```json
{
  "type": "brain_zone_changed",
  "data": {
    "zone": "hot",
    "entry_id": "uuid",
    "change_type": "created"
  }
}
```

---

### `brain_specialist_recruited`

触发前端非模态 toast 通知（专员名 + reason，点击跳转专员管理页）。

```json
{
  "type": "brain_specialist_recruited",
  "data": {
    "specialist_id": "uuid",
    "name": "数据分析专员",
    "reason": "...",
    "management_url": "/brain/specialists"
  }
}
```

---

### `brain_context_ready`

通知前端大脑上下文就绪（如需 UI 反馈可用）。

```json
{
  "type": "brain_context_ready",
  "data": {
    "session_id": "uuid"
  }
}
```
