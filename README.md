## ✨ 核心优势

### 🔒 本地化存储，完全离线，安全可控

**你的数据，完全掌控**：
- 🏠 **默认本地存储** - 所有录制数据、工具定义、执行记录都存储在本地数据库
- 📱 **完全离线工作** - 不需要联网也能正常使用，AI 调用除外
- 🔐 **数据安全** - 敏感信息不会离开你的电脑，零泄露风险
- 💾 **数据主权** - 你是数据的唯一所有者，可以随时备份、删除、迁移
- ☁️ **可选云端备份** - 支持自动备份到云端（可选功能）

**与云端方案对比**：

| 特性 | Mexemplar | 云端 Agent |
|------|-----------|-----------|
| 数据存储 | 本地数据库 | 云服务器 |
| 离线工作 | ✅ 支持 | ❌ 需要联网 |
| 数据隐私 | ✅ 默认本地 | ⚠️ 上传到云端 |
| API 费用 | 仅 AI 分析时 | 每次调用都收费 |
| 云端作用 | ☁️ 可选备份 | ⚠️ 计算和存储 |

## 💡 关于 Mexemplar

**Mexemplar** 是一个**桌面端智能办公助理**，通过**观察和学习**你的操作示例来理解工作流程，然后自动完成重复性任务。

### 为什么开源？

我决定将 Mexemplar 开源，出于以下原因：

- 🌱 **在开放中成长**：我深信开源是最好的学习方式。通过分享这个项目，我希望能够融入技术社区，接收来自各方的建议和反馈，在与他人的交流中不断提升自己的技术能力和视野。

- 🚀 **用行动对抗焦虑**：在这个充满不确定性的时期，我选择停下来不再空想，而是脚踏实地去做一些真正想做的事情。相信每一步实际行动都比完美的计划更有价值。

- 🤝 **传递行动的力量**：如果屏幕前的你也正处于人生的困顿期，我希望这个项目能给你一些启发：不要等待完美的时机，不要害怕不够优秀，先动起来。每一个小小的行动都是打破困境的开始。让我们一起在实践中寻找答案。

- 🔐 **探索更安全的路径**：Mexemplar 的核心设计理念是"数据不出本地"：
  - ✅ 所有录制数据存储在本地 DuckDB 数据库
  - ✅ 工具定义存储在本地 SQLite 数据库
  - ✅ 执行过程完全离线，无需上传数据到云端
  - ✅ 只在你主动调用 AI 时才需要联网（生成工具时）
  - ⚠️ 这比传统的云端 AI Agent 更安全、更私密

- 🌟 **展示与连接**：开源项目是最好的自我展示。这个项目很庞大甚至超出我的能力范围，但我依旧希望通过 Mexemplar 展示我的技术能力和产品思维，也期待能够与志同道合的人建立联系，碰撞出更多可能性。

### 开发方式

本项目采用 **Vibe Coding** 方式开发——一种新兴的 AI 辅助编程范式。

与传统编程不同，Vibe Coding 强调：
- 💬 **对话式开发**：通过自然语言与 AI 协作，而非手工编写每一行代码
- 🎯 **意图驱动**：专注于描述"要做什么"，而非"怎么做"
- 🔄 **快速迭代**：AI 生成代码，人类审查和引导，循环往复
- 🌊 **跟随直觉**：让想法自然流淌，在实现中完善细节

**技术栈**：
- 🤖 **Claude Code**  - 主要的 AI 编程助手
- 🧠 **GLM-4.7 API**  - 辅助的 AI 模型

这种开发方式让我的想法能够快速落地，也让我更专注于产品逻辑和用户体验，而非陷入实现细节。我相信这是未来编程的一种重要方式。

## 🔒 隐私与成本说明

### 数据存储架构

**所有数据存储在本地，不会上传到云端**：

```
本地数据库（主要工作区域）
├── SQLite 业务数据库 (data/mexemplar.db)
│   ├── tools                    # 工具定义（你演示的工作流程）
│   ├── task_executions          # 执行记录
│   └── conversations            # 对话历史
│
└── DuckDB 录制数据库 (data/mexemplar.duckdb)
    ├── recording_sessions       # 录制会话
    ├── actions                   # 操作记录
    ├── network_requests          # 网络请求
    ├── sibling_snapshots         # 兄弟元素快照（列表定位）
    └── list_contexts            # 列表上下文（列表操作）

可选云端备份
└── 云端备份服务
    └── 自动备份数据库文件（需用户手动启用）
```

**数据流说明**：
1. **教学阶段**（本地 AI 分析）→ 只在生成工具时调用 AI API
2. **执行阶段**（完全离线）→ 所有操作在本地完成，无需联网
3. **备份阶段**（可选）→ 用户启用后自动备份到云端

**隐私保证**：
- ✅ 录制数据只在本地
- ✅ 工具定义保存在本地
- ✅ 执行过程完全离线，不需要联网
- ✅ 完全掌控你的数据
- ☁️ **云端备份完全可选**

### Token 使用策略

**智能 Token 管理，最大化节省成本**：

| 使用阶段 | Token 消耗 | 成本 |
|---------|-----------|------|
| 教学阶段（演示操作） | ~2000-5000 | $0.006-0.015 |
| 执行阶段（运行工具） | 0 | $0 |
| 修改工具（重新分析） | ~1000-3000 | $0.003-0.009 |
| 日常使用（无限次执行） | 0 | $0 |

**成本对比**（假设每月使用 100 次）：
